# ทีมงาน somtum.fun

somtum.fun ดูแลโดยอาสาสมัคร หน้าของแต่ละกลุ่มแสดงรายชื่อสมาชิกปัจจุบัน

| กลุ่ม | หน้าที่ |
| :-- | :-- |
| [Administrators](/groups/admin) | ดูแลเซิร์ฟเวอร์และเว็บไซต์ และมีคำตัดสินสุดท้าย |
| [Developers](/groups/dev) | พัฒนา TumThai เซิร์ฟเวอร์เกม เว็บไซต์ และเครื่องมือของเรา |
| [Global Moderation Team](/groups/gmt) | ดูแลแชท ฟอรัม และโปรไฟล์ให้เป็นมิตร และตรวจรายงาน |
| [Support Team](/groups/spt) | ช่วยผู้เล่นเรื่องบัญชีและปัญหาต่าง ๆ |
| [Nomination Assessment Team](/groups/nat) | ดูแล Beatmap Nominator และคุณภาพการแรงก์ |
| [Beatmap Nominators](/groups/bng) | หาและเสนอชื่อแมพเพื่อแรงก์ (รวมถึงสมาชิก[ช่วงทดลอง](/groups/bng_limited)) |
| [Project Loved](/groups/loved) | เลือกแมพสำหรับหมวด Loved |
| [Medal Team](/groups/medal) | พิจารณา[เหรียญที่ผู้เล่นขอเพิ่ม](/community/medals) |
| [Tournament Committee](/groups/tc) | จัดทัวร์นาเมนต์ของเรา |
| [Alumni](/groups/alumni) | อดีตทีมงานที่ช่วยสร้าง somtum.fun |

อยากช่วย? Beatmap Nominator สมัครได้ที่ [BN Management](https://bn.somtum.fun/) Project Loved รับสมาชิกใหม่เป็นรอบ ๆ โดยประกาศใน[ข่าว](/home/news) และใน [Discord](https://discord.gg/U6Ztb3mRyz) ของเรา ดู[การเข้ากลุ่ม](/wiki/People/User_groups#joining)

ป้ายและฉายาข้างชื่อหมายถึงอะไร: [กลุ่มผู้ใช้](/wiki/People/User_groups) และ[ฉายาผู้ใช้](/wiki/People/User_title)

ต้องการความช่วยเหลือ? ดู[ศูนย์ช่วยเหลือ](/wiki/Help_centre) โปรดใช้ช่องทางช่วยเหลือแทนการส่งข้อความหาทีมงานโดยตรง
