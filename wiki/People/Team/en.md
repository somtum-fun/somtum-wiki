# The somtum.fun team

somtum.fun is run by volunteers. Each group's page lists its current members.

| Group | What they do |
| :-- | :-- |
| [Administrators](/groups/1) | Run the server and the website, and have the final say. |
| [Developers](/groups/8) | Build TumThai, the game server, the website and our tools. |
| [Global Moderation Team](/groups/9) | Keep the chat, forums and profiles friendly, and look at reports. |
| [Support Team](/groups/14) | Help players with their accounts and problems. |
| [Nomination Assessment Team](/groups/11) | Look after the Beatmap Nominators and ranking quality. |
| [Beatmap Nominators](/groups/4) | Find and nominate maps for ranking ([probationary](/groups/5) members too). |
| [Project Loved](/groups/10) | Choose maps for the Loved category. |
| [Tournament Committee](/groups/15) | Run our tournaments. |
| [Alumni](/groups/2) | Former staff who helped build somtum.fun. |

What the badges and titles next to names mean: [User groups](/wiki/People/User_groups) and [User titles](/wiki/People/User_title).

Need help? See the [Help centre](/wiki/Help_centre). Please use the support channels instead of messaging staff directly.
