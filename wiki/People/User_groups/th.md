# กลุ่มผู้ใช้

**กลุ่มผู้ใช้**บอกว่าผู้เล่นทำหน้าที่อะไรบน somtum.fun กลุ่มจะแสดงเป็นป้ายสั้น ๆ ข้างชื่อผู้เล่น (เช่น **GMT** หรือ **BN**) และชื่อกับ[ฉายา](/wiki/People/User_title)ของผู้เล่นจะเป็นสีของกลุ่มหลัก คลิกป้ายเพื่อดูทุกคนในกลุ่มนั้น

## กลุ่มทีมงาน {id=team}

คนเหล่านี้คือผู้ดูแล somtum.fun หน้าที่ของแต่ละทีมอยู่ใน[หน้าทีมงาน](/wiki/People/Team) และการเปลี่ยนแปลงแสดงอย่างเปิดเผยใน[บันทึกทีมงาน](/wiki/People/Staff_log)

| ป้าย | กลุ่ม | |
| :-- | :-- | :-- |
| ADM | [Administrators](/groups/admin) | ดูแลเซิร์ฟเวอร์และเว็บไซต์ |
| DEV | [Developers](/groups/dev) | พัฒนา TumThai เซิร์ฟเวอร์เกม เว็บไซต์ และเครื่องมือของเรา |
| GMT | [Global Moderation Team](/groups/gmt) | ดูแลแชท ฟอรัม และโปรไฟล์ และตรวจรายงาน |
| SPT | [Support Team](/groups/spt) | ช่วยผู้เล่นเรื่องบัญชีและปัญหาต่าง ๆ |
| NAT | [Nomination Assessment Team](/groups/nat) | ดูแล Beatmap Nominator และคุณภาพการแรงก์ |
| BN | [Beatmap Nominators](/groups/bng) และ [BN ช่วงทดลอง](/groups/bng_limited) | เสนอชื่อแมพเพื่อแรงก์ |
| LVD | [Project Loved](/groups/loved) | เลือกแมพสำหรับหมวด Loved |
| TC | [Tournament Committee](/groups/tc) | จัดทัวร์นาเมนต์ของเรา |
| MDL | [Medal Team](/groups/medal) | พิจารณา[เหรียญที่ผู้เล่นขอเพิ่ม](/community/medals) |
| ALM | [Alumni](/groups/alumni) | อดีตทีมงาน ขอบคุณสำหรับสิ่งที่ทำมา |

บางกลุ่ม (BN, NAT, Project Loved) แสดงโหมดเกมที่รับผิดชอบเป็นไอคอนโหมดเล็ก ๆ ข้างป้าย

## กลุ่มอื่น ๆ {id=other}

| ป้าย | กลุ่ม | |
| :-- | :-- | :-- |
| BOT | [Chat Bots](/groups/bot) | บัญชีที่โปรแกรมควบคุม (ดู[บัญชีบอต](/wiki/Bot_account)) แชทผ่าน IRC ได้แต่เล่นเกมไม่ได้ |
| FA | [Featured Artist](/groups/featured_artist) | นักดนตรีที่มีเพลงอยู่ในรายการ featured artist ของ somtum.fun |

**Supporter** ไม่ใช่กลุ่ม supporter จะได้รูปหัวใจในโปรไฟล์แทน

## การเข้ากลุ่ม {id=joining}

คุณเพิ่มตัวเองเข้ากลุ่มไม่ได้ ทีมงานเป็นคนเพิ่ม:

- **Beatmap Nominator:** สมัครที่ [BN Management](https://bn.somtum.fun/) (ล็อกอินด้วยบัญชี somtum.fun) NAT เป็นผู้ตัดสิน ดู[การเป็น Beatmap Nominator](/wiki/Beatmap_ranking_procedure#becoming-a-bn)
- **Project Loved** รับสมาชิกใหม่เป็นรอบ ๆ เมื่อเปิดรับ เราจะประกาศใน[ข่าว](/home/news) และใน [Discord](https://discord.gg/U6Ztb3mRyz) ติดตามช่องทางใดช่องทางหนึ่งไว้
- **ทีมอื่น ๆ** จะประกาศหาคนช่วยเมื่อต้องการใน [Discord](https://discord.gg/U6Ztb3mRyz) ของเรา การเป็นมิตรและช่วยเหลือคนในชุมชนคือวิธีที่ดีที่สุดที่จะเป็นที่สังเกต
- **Chat Bots:** ดู[บัญชีบอต](/wiki/Bot_account)

กลุ่มให้เครื่องมือบนเว็บไซต์และในเกมแก่สมาชิกเฉพาะงานนั้นเท่านั้น ทีมงานจะไม่ขอรหัสผ่านของคุณเด็ดขาด
