# osu!dan

osu!dan คือชุด**คอร์ส**สำหรับ osu!mania: แมพมาราธอนยาว ๆ ที่ทดสอบความสม่ำเสมอ ความอึด และการอ่านโน้ต ผ่านคอร์สแล้วจะแสดงในประวัติของคุณ ผ่านคอร์สถัดไปเพื่อเลื่อนขั้น คอร์สและกติกาของ somtum.fun มาจาก [Dan ~ REFORM ~](https://www.danreform.com/) (DanReform) ซึ่งเป็นโปรเจกต์ของชุมชน ไม่ใช่เว็บไซต์ทางการของ osu! จึงควรปฏิบัติตามกติกาของ DanReform สำหรับคอร์สของเขาด้วย

ดูทุกคอร์ส แมพในคอร์ส และใครผ่านแล้วได้ที่[หน้า osu!dan](/community/dan) คอร์สจะขึ้นเมื่อทีมงานเพิ่ม

## กติกา {id=rules}

การเล่นจะนับเป็น**การผ่าน (clear)** ก็ต่อเมื่อครบทุกข้อ:

- **osu!mania** ใน **osu!(stable)** (osu! ปัจจุบันผ่าน Somtum Patcher หรือไคลเอนต์รุ่นเก่าที่แพตช์แล้วตั้งแต่กลางปี 2013 ขึ้นไป) หรือใน **TumThai** (osu!lazer ของเรา) พร้อมม็อด Classic: ดู[ด้านล่าง](#lazer)
- **ห้ามหยุดเกม** LimeBot จะดูคุณเล่นระหว่างเล่นแมพในคอร์ส (จะเห็นข้อความ "LimeBot is spectating") เพื่อให้รู้ว่าคุณหยุดหรือไม่
- **ความแม่นยำ:** 96% ขึ้นไป หรือ 95% สำหรับคอร์ส intro ใช้ค่าความแม่นยำที่เกมแสดง ทศนิยมสองตำแหน่ง
- **เฉพาะม็อดที่อนุญาต:** Mirror, Hidden, Fade In, Flashlight, Hard Rock, Double Time และ Nightcore เว้นแต่คอร์สจะกำหนดเป็นอย่างอื่น
- **ต้องผ่านแมพ** การเล่นที่ fail ไม่นับเป็นการผ่าน

คอร์สที่มีหลายแมพจะนับว่าผ่านเมื่อทุกแมพในคอร์สมีการผ่านแล้ว ถ้าผ่านคอร์สซ้ำ จะเก็บวันที่ผ่านครั้งแรกและความแม่นยำที่ดีที่สุดไว้

## การเล่นที่ไม่นับจะเป็นอย่างไร {id=not-a-clear}

ใน osu!(stable) ยังเป็น**คะแนนปกติ**: อยู่บนลีดเดอร์บอร์ดและในสถิติของคุณ แค่ไม่นับเป็นการผ่าน dan (ใน TumThai การเล่นที่ผิดกติกาจะไม่ถูกเก็บ ดู [osu!lazer และ TumThai](#lazer)) LimeBot จะบอกเหตุผล เช่น:

| LimeBot บอกว่า | ต้องทำอะไร |
| :-- | :-- |
| *you paused, so this … attempt won't count as a clear* | เล่นแมพใหม่ (retry จะเริ่มรอบใหม่) และอย่าหยุดเกม |
| *… isn't allowed here, so this play won't count* | ถอดม็อดนั้นออก นับเฉพาะม็อดที่อนุญาตข้างบน |
| *it needs 96% accuracy* | เล่นใหม่ให้แม่นยำขึ้น |
| *it wasn't played in osu!mania* | เล่นคอร์สในโหมด osu!mania ไม่ใช่แปลงเป็นโหมดอื่น |
| *LimeBot couldn't watch the play* | คุณเริ่มแมพก่อนที่ LimeBot จะเริ่มดูได้ หรือการเชื่อมต่อหลุด เล่นใหม่อีกครั้ง |
| *this osu! version can't be watched for pauses* | รุ่นก่อนพฤษภาคม 2013 ดูการหยุดเกมไม่ได้ ใช้ Somtum Patcher หรือไคลเอนต์ที่แพตช์แล้วรุ่นที่ใหม่กว่าจาก[หน้าดาวน์โหลด](/home/download) |

## คำสั่งแชท {id=commands}

พิมพ์ในแชทไหนก็ได้ หรือส่งข้อความส่วนตัวหา LimeBot:

| คำสั่ง | แสดงอะไร |
| :-- | :-- |
| `!dan` | การผ่านสูงสุดของคุณในแต่ละจำนวนคีย์ และคอร์สถัดไปที่ควรลอง |
| `!dan <player>` | ของผู้เล่นคนอื่น |
| `!dan list` | ทุกคอร์ส |
| `!dan rules` | กติกาแบบย่อ |

## osu!lazer และ TumThai {id=lazer}

คุณเล่นคอร์ส dan ใน TumThai (osu!lazer ของเรา) ได้ ด้วยกติกาเดียวกัน:

- **เปิดม็อด Classic (CL)** ถ้าไม่เปิด TumThai จะแสดง "Score will not be submitted" และบอกเหตุผล TumThai เวอร์ชันเก่าจะถูกขอให้อัปเดต
- **ห้ามหยุดเกม** การหยุดครั้งแรกจะแจ้งว่าการเล่นนี้นับไม่ได้ และการเล่นที่หยุดจะไม่ถูกส่ง
- **[กติกา](#rules)ข้ออื่นก็ใช้ด้วย:** osu!mania เท่านั้น เฉพาะม็อดที่อนุญาต (ม็อดเฉพาะ lazer หรือม็อดที่มีการตั้งค่าของตัวเองไม่อนุญาต) และความแม่นยำตามคอร์ส นับแบบที่ osu!(stable) นับ

การเล่นใน TumThai ที่ทำตามกติกาจะขึ้นบนลีดเดอร์บอร์ดของแมพและในสถิติเหมือนคะแนนอื่น และ**นับเป็นการผ่าน** ภายในไม่กี่นาทีหลังเล่นจบ (เมื่อเซิร์ฟเวอร์ประมวลผลเสร็จ) การเล่นที่ผิดกติกาจะไม่ถูกเก็บเลย

สำหรับ TumThai เซิร์ฟเวอร์ spectator ของเราเป็นคนดูแทน LimeBot ซึ่งเป็นวิธีที่เซิร์ฟเวอร์รู้ว่าคุณไม่ได้หยุดเกม การเล่นที่มันไม่เห็น (เช่น การเชื่อมต่อกับมันหลุด) ไม่นับเป็นการผ่าน ให้เล่นใหม่ แมพ dan เล่นในมัลติเพลเยอร์หรือ playlist ไม่ได้
