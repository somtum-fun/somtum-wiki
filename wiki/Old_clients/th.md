# ไคลเอนต์ osu! รุ่นเก่า (2008-2015)

somtum.fun ให้คุณเล่น osu! แบบเมื่อก่อนได้ เราสร้าง**ไคลเอนต์ osu! 75 รุ่นจากปี 2008 ถึง 2015** ขึ้นใหม่ให้เชื่อมต่อกับเซิร์ฟเวอร์ของเรา เล่นเวอร์ชันที่คุณเริ่มเล่นครั้งแรกได้ และคะแนนยังอยู่บนลีดเดอร์บอร์ดเดียวกับ osu!(stable) และ lazer (TumThai) ในปัจจุบัน

## วิธีติดตั้ง {id=getting-one}

1. เลือกรุ่นที่ต้องการใน[หน้าดาวน์โหลด](/home/download) หรือให้ **Somtum Launcher** ติดตั้งให้
2. แตกไฟล์ไว้ที่ไหนก็ได้ แล้วเปิด `osu!.exe`
3. เก็บ `pkms.dll` (ระบบกันโกงของเรา) ไว้ข้าง `osu!.exe` ถ้าไม่มีไฟล์นี้ คะแนนจะไม่ถูกส่ง

ไคลเอนต์รุ่นเก่าต้องใช้ Windows และ .NET Framework 3.5 (บางรุ่นปี 2015 ใช้ .NET Framework 4)

## ล็อกอินได้เฉพาะรุ่นของเรา {id=only-our-builds}

แต่ละรุ่นคือไฟล์ที่เราแก้สำหรับเวอร์ชันนั้นโดยเฉพาะ รุ่นต้นฉบับที่ไม่ได้แก้ รุ่นที่ใช้ hook ตัวเก่า หรือรุ่นที่คุณสร้างใหม่เองจะเชื่อมต่อไม่ได้ ดู ["This old osu! build can't play on somtum.fun as it is"](/wiki/FAQ#error-old-build)
