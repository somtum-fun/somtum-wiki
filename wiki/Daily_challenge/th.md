# ภารกิจรายวัน (Daily challenge)

**Daily challenge** คือกิจกรรมรายวันของ osu!lazer เอง และบน somtum.fun ก็ทำงานแบบเดียวกัน ทุกวันจะมีแมพใหม่เปิดในห้อง playlist ใน **TumThai** เล่นกี่ครั้งก็ได้ และคะแนนที่ดีที่สุดจะนับ เปิดได้จากเมนูหลัก: **Play → Daily challenge**

## ทำงานอย่างไร {id=how-it-works}

- ภารกิจใหม่เปิดทุกวันเวลา **00:05 UTC** (07:05 น. เวลาไทย) และเปิดไปจนกว่าภารกิจถัดไปจะเปิด TumThai จะแจ้งเมื่อมีภารกิจใหม่
- นับเฉพาะการเล่น**ในห้อง daily challenge** เท่านั้น การเล่นแมพเดียวกันจากหน้าเลือกเพลงไม่นับ
- ลีดเดอร์บอร์ดของห้องจัดอันดับผู้เล่นตาม**คะแนนรวมที่ดีที่สุด** คุณจะเห็นคะแนนใหม่ของผู้เล่นอื่นทันทีที่เข้ามา
- หลังจบแต่ละวัน ระบบจะคำนวณ **streak** (จำนวนวันติดต่อกันที่คุณเล่น) และอันดับของคุณ (percentile) ซึ่งแสดงในโปรไฟล์และใน[อันดับ daily challenge](/rankings/daily-challenge)
- บอต Discord ของเราโพสต์ภารกิจของแต่ละวันใน[เซิร์ฟเวอร์ Discord](https://discord.gg/U6Ztb3mRyz) และโพสต์ห้าอันดับแรกเมื่อจบ

Daily challenge มีเฉพาะใน **TumThai (osu!lazer)** เท่านั้น osu!(stable) ไม่มี daily challenge

## แมพ {id=maps}

ทุกแมพถูกเลือกอัตโนมัติจากแมพ **ranked** ที่ยังไม่เคยเป็น daily challenge ยาว 1 ถึง 5 นาที เหมือนบน osu! สัปดาห์จะเริ่มจากง่ายแล้วยากขึ้นเรื่อย ๆ:

| วัน | ระดับดาว |
| :-- | :-- |
| พฤหัสบดี | 3 ถึง 3.5★ |
| ศุกร์ | 3.5 ถึง 4★ |
| เสาร์ | 4 ถึง 4.5★ |
| อาทิตย์ | 4.5 ถึง 5★ |
| จันทร์ | 5 ถึง 5.5★ |
| อังคาร | 5.5 ถึง 6★ |
| พุธ | 6 ถึง 6.5★ |

ตอนนี้ภารกิจเป็นโหมด **osu!** เท่านั้น

## ม็อด {id=mods}

ใส่ม็อดเหล่านี้ได้ แต่ห้ามม็อดที่เปลี่ยนความเร็ว (ไม่มี Double Time, Half Time และอื่น ๆ ทำนองนี้):

| โหมด | ม็อดที่ใช้ได้ |
| :-- | :-- |
| osu!, osu!taiko, osu!catch | Easy, No Fail, Hidden, Hard Rock, Sudden Death, Perfect, Flashlight |
| osu!mania | Easy, No Fail, Hidden, Fade In, Sudden Death, Perfect, Flashlight, Mirror |

## Daily challenge หรือแมพประจำวัน? {id=map-of-the-day}

somtum.fun ยังมี[แมพประจำวัน (map of the day)](/wiki/Map_of_the_day) บน Discord ด้วย ซึ่งเป็นคนละอย่างกัน:

| | Daily challenge | แมพประจำวัน |
| :-- | :-- | :-- |
| เล่นที่ไหน | ห้องใน TumThai | การเล่นแมพนั้นตามปกติ ใน TumThai หรือ osu!(stable) |
| แมพ | Ranked ยาว 1–5 นาที ยากขึ้นทุกวันในสัปดาห์ | แมพ ranked สุ่ม 3–6.5★ ยาว 1–7 นาที |
| ม็อด | เฉพาะที่ระบุข้างบน | อะไรก็ได้ (ยกเว้น Relax และ Autopilot) |
| ใครชนะ | คะแนนรวมสูงสุดในห้อง | การผ่านที่ดีที่สุดของวันนั้นตาม pp แล้วตามคะแนน |
| รางวัล | Streak, percentile และอันดับ daily challenge | role Map of the Day ใน Discord หนึ่งสัปดาห์ |
