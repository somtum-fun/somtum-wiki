## 1. บทนำ

somtum.fun ("เรา") เป็นเซิร์ฟเวอร์ osu! ส่วนตัวที่ดำเนินการโดยบุคคลธรรมดาและดูแลโดยทีมงาน somtum.fun ความเป็นส่วนตัวของคุณสำคัญกับเรา นโยบายนี้อธิบายว่าเราเก็บ ใช้ และปกป้องข้อมูลส่วนบุคคลของคุณอย่างไร

เมื่อสมัครและใช้ somtum.fun ถือว่าคุณยินยอมให้เก็บและใช้ข้อมูลตามนโยบายนี้

## 2. การเก็บข้อมูล

เราเก็บข้อมูลส่วนบุคคลต่อไปนี้เมื่อคุณสมัครและใช้บริการ:

- ชื่อผู้ใช้
- อีเมล
- รหัสผ่าน (เข้ารหัสแบบแฮชอย่างปลอดภัยด้วย bcrypt + salt)
- IP address และประเทศ
- ข้อมูลการเล่น (คะแนน อันดับ ความสำเร็จ และสถิติที่เกี่ยวข้อง)

### 2.1 เมื่อแก้ไขโปรไฟล์

เมื่อสร้างโปรไฟล์ (ซึ่งผู้ใช้คนอื่นทุกคนมองเห็นได้) คุณเลือกใส่ข้อมูลเหล่านี้ได้:

- ที่อยู่ปัจจุบัน
- ความสนใจ
- อาชีพ
- โซเชียลมีเดีย (Twitter, Discord, Skype, เว็บไซต์)
- รูปโปรไฟล์และภาพปก
- ลายเซ็น

ข้อมูลทั้งหมดข้างต้นเป็นสาธารณะ แต่ลบได้ทันทีและถาวรเมื่อใดก็ได้ในหน้าการตั้งค่า

### 2.2 เมื่ออัปโหลดเนื้อหา

เมื่อโพสต์ในฟอรัม แชท หรืออัปโหลดเนื้อหา เช่น บีทแมพ คุณกำลังทำให้เนื้อหาที่ส่งทั้งหมดเป็นสาธารณะ ส่วนใหญ่คุณแก้ไขหรือลบได้ภายหลังตามต้องการ แต่ในบางกรณีอาจถูกจำกัดเพื่อรักษาความถูกต้องและความสมบูรณ์ของบริการ

ตัวอย่างเช่น ถ้าคุณอัปโหลดบีทแมพแล้วได้ "แรงก์" บีทแมพนั้นจะกลายเป็นพื้นฐานที่ผู้เล่นจำนวนมากใช้ทำคะแนน เมื่อถึงตอนนั้น ตัวเลือกลบจะถูกยกเลิก

### 2.3 เมื่อล็อกอินไคลเอนต์เกม

เมื่อเชื่อมต่อจากไคลเอนต์เกม osu! จะมีการส่งข้อความเฉพาะของไคลเอนต์มาเพื่อช่วยระบุสภาพแวดล้อมที่คุณเล่น ข้อความนี้สร้างจากตัวระบุฮาร์ดแวร์และซอฟต์แวร์ และถูกแฮชจนไม่มีข้อมูลที่ระบุตัวบุคคลได้ แต่ใช้ติดตามการเข้าใช้ข้ามการล็อกอินได้

จุดประสงค์หลักคือรักษาระบบอันดับให้ยุติธรรม และรักษาความปลอดภัยของบัญชีในกรณีที่มีการเข้าถึงโดยไม่ได้รับอนุญาต ข้อมูลนี้เป็นข้อมูลส่วนตัว เก็บไว้เท่าที่จำเป็น และไม่ถ่ายโอนให้ผู้อื่น

### 2.4 เมื่อเล่นเกมและส่งคะแนน

เมื่อเล่นจบ (ไม่ว่าจะผ่านหรือไม่ผ่านบีทแมพ) รายละเอียดผลการเล่นจะถูกส่งมาที่เซิร์ฟเวอร์ของเราโดยอัตโนมัติ รวมถึงข้อมูลรีเพลย์และคะแนน ซึ่งอาจแสดงต่อสาธารณะบนลีดเดอร์บอร์ดและในโปรไฟล์ของคุณ บันทึกเหล่านี้ลบหรือแก้ไขไม่ได้

### 2.5 ระบบกันโกง

เราตรวจการโกงสองที่: บนเซิร์ฟเวอร์ของเรา และในเกมบนคอมของคุณ

**บนเซิร์ฟเวอร์ของเรา** ทุกรีเพลย์ที่ส่งมาจะถูกวิเคราะห์ (ตัวตรวจรีเพลย์ของเราพัฒนาจาก circleguard): จังหวะที่สม่ำเสมอเกินกว่ามนุษย์ เคอร์เซอร์ที่ดูดเข้าหาโน้ต (aim assist) เกมที่ทำงานเร็วกว่าที่ควร (timewarp) การกดที่จะเกิดได้ก็ต่อเมื่อขนาดวงกลมหรือ hit window ถูกแก้ และรีเพลย์ที่ลอกมาจากผู้เล่นอื่น ส่วนนี้ใช้แค่ข้อมูลการเล่นในข้อ 2.4

**ในเกม** ระบบกันโกงฝั่งไคลเอนต์ของเรา (ชื่อ *pkms*) ทำงานภายใน process ของ osu! เองเมื่อคุณเล่น osu!(stable) ผ่าน **Somtum Patcher** และใน**ไคลเอนต์รุ่นเก่า** (2008 ถึง 2015) ที่ดาวน์โหลดจากเว็บไซต์หรือ Somtum Launcher ของเรา ซึ่งยังลงลายเซ็นการล็อกอินและทุกคะแนน เพื่อให้เรารู้ว่ามาจากไคลเอนต์ที่ไม่ถูกแก้ไข มันเป็นโปรแกรม Windows ธรรมดาที่ทำงานด้วยสิทธิ์ของบัญชีผู้ใช้ของคุณ (**user mode**):

- มัน**ไม่ใช่ kernel driver** ไม่ติดตั้งไดรเวอร์หรือ service ไม่เพิ่มอะไรให้เริ่มพร้อม Windows และหยุดทำงานทั้งหมดเมื่อปิด osu!
- มันดูแค่ **osu! เท่านั้น**: หน่วยความจำและโค้ดของ osu! (เพื่อดูว่าถูกแก้หรือไม่) ไลบรารีที่โหลดเข้า osu! โปรแกรมที่เปิดหน่วยความจำของ osu! debugger ที่เกาะ osu! และการกดคีย์บอร์ดหรือเมาส์ที่โปรแกรมสร้างขึ้นแทนอุปกรณ์จริง สำหรับอินพุต มันนับแค่เหตุการณ์ที่ถูกสร้างขึ้น ไม่เคยบันทึกว่าคุณกดปุ่มไหนหรือขยับเมาส์ไปทางไหน
- มัน**ไม่**อ่านไฟล์ เอกสาร ข้อมูลเบราว์เซอร์ หน้าจอ ไมโครโฟน หรือกล้องของคุณ และไม่ส่งรายการโปรแกรมที่ทำงานอยู่บนคอมของคุณมาให้เรา ในการหาโปรแกรมที่เปิดหน่วยความจำของ osu! มันดูว่าโปรแกรมไหนถือ handle ของ osu! อยู่ และรายงานเฉพาะโปรแกรมเหล่านั้น
- โอเวอร์เลย์และโปรแกรมอัดหน้าจอทั่วไป (Discord, Steam, OBS, NVIDIA, AMD, RivaTuner และอื่น ๆ ทำนองนี้) ใช้ได้

ระหว่างที่ osu! ทำงาน ระบบกันโกงจะส่งข้อมูลเหล่านี้มาที่เซิร์ฟเวอร์:

- **ตัวระบุอุปกรณ์**: ค่าแฮชทางเดียวที่สร้างจาก ID ของ Windows ที่ติดตั้ง หมายเลขซีเรียลของไดรฟ์ระบบ และรุ่นของโปรเซสเซอร์ รวมกับตัวระบุที่แฮชแล้วซึ่งไคลเอนต์ osu! ส่งเอง (ข้อ 2.3) ค่านี้บันทึกไว้ในคอมของคุณที่ `Software\pkms` ใน Windows registry เพื่อให้คงที่ แปลงกลับเป็นข้อมูลฮาร์ดแวร์ไม่ได้ แต่บอกได้ว่ามีสองบัญชีใช้คอมเครื่องเดียวกัน
- **เวอร์ชันของ Patcher** และ checksum ของโค้ด osu! และโค้ดของระบบกันโกงเอง
- **สิ่งที่ตรวจเจอ** ถ้ามี: การตรวจข้อไหนทำงาน และถ้ามีโปรแกรมอื่นเกี่ยวข้อง จะส่งชื่อและที่อยู่ไฟล์ของโปรแกรมนั้น
- ข้อความสั้น ๆ ที่ลงลายเซ็นว่า "ยังทำงานอยู่" ทุกไม่กี่วินาที และคำตอบที่ลงลายเซ็นเมื่อคุณส่งคะแนน เพื่อให้เรารู้ว่าระบบกันโกงทำงานอยู่จริง

IP address ของคุณจะถูกเห็นพร้อมข้อความเหล่านี้เหมือนการเชื่อมต่อทั่วไป เฉพาะทีมงาน somtum.fun เท่านั้นที่เห็นผลของระบบกันโกง ข้อมูลเก็บไว้กับบันทึกการดูแลบัญชีของคุณ และใช้เพื่อรักษาลีดเดอร์บอร์ดให้ยุติธรรมและป้องกันการหลบเลี่ยงการจำกัดบัญชีเท่านั้น คุณขอดูข้อมูลที่เรามี หรือขอลบพร้อมบัญชีได้ (ข้อ 9)

**TumThai** (osu!lazer ของเรา) ไม่มีระบบกันโกงฝั่งไคลเอนต์ เหมือน osu!lazer ทางการ มันส่งแค่เวอร์ชันเพื่อให้เราปฏิเสธเวอร์ชันที่เก่าหรือถูกแก้ไขได้ การเล่นของมันถูกตรวจบนเซิร์ฟเวอร์เหมือนของคนอื่น

## 3. การใช้ข้อมูล

ข้อมูลของคุณใช้เพื่อวัตถุประสงค์ต่อไปนี้เท่านั้น:

- **สถิติการเล่นและลีดเดอร์บอร์ด** – เพื่อให้ประสบการณ์ที่สนุกพร้อมการเก็บคะแนนที่ถูกต้อง
- **ความปลอดภัยและการดูแล** – เพื่อป้องกันการโกง บังคับใช้กฎ และจัดการการแบนและการอุทธรณ์
- **การจัดการบัญชี** – เพื่อให้ผู้ใช้ล็อกอิน เล่น และมีส่วนร่วมกับชุมชนได้

เราไม่แชร์ ขาย หรือเผยแพร่ข้อมูลของคุณให้บุคคลที่สาม เฉพาะทีมงาน somtum.fun เท่านั้นที่เข้าถึงข้อมูลนี้ได้

## 4. คุกกี้และการติดตาม

เราไม่ใช้คุกกี้หรือเทคโนโลยีติดตามเพื่อตรวจดูกิจกรรมของผู้ใช้ เกินกว่าที่จำเป็นต่อการทำงานของเว็บไซต์

บริการเว็บไซต์ทั้งหมดผ่าน Cloudflare เพื่อความปลอดภัย ประสิทธิภาพ และความเสถียร

## 5. ข้อมูลการชำระเงิน

หากคุณบริจาคหรือซื้อสินค้า เราเก็บแค่ชื่อตามกฎหมายของคุณ เราไม่มีสิทธิ์เข้าถึงรายละเอียดบัตรเดบิตหรือบัตรเครดิต เพราะการชำระเงินดำเนินการอย่างปลอดภัยโดยผู้ให้บริการชำระเงินภายนอก

ดูรายละเอียดเพิ่มเติมได้ในนโยบายความเป็นส่วนตัวของผู้ให้บริการแต่ละราย:

- นโยบายความเป็นส่วนตัวของ TrueMoney (สำหรับผู้เล่นในประเทศไทย): [https://www.truemoney.com/privacy-notice](https://www.truemoney.com/privacy-notice)
- นโยบายความเป็นส่วนตัวของ Stripe (สำหรับผู้เล่นนอกประเทศไทย): [https://stripe.com/th/privacy](https://stripe.com/th/privacy)

ข้อมูลของคุณและโครงสร้างพื้นฐานของเซิร์ฟเวอร์ถูกสำรองและโฮสต์โดย:

- [Oracle Cloud](https://www.oracle.com/asean/cloud/) (ตั้งอยู่ในสิงคโปร์ ดำเนินการโดย Oracle Corporation)

ผู้ให้บริการนี้ใช้เพื่อให้ระบบพร้อมใช้งานสูง มีการสำรอง และมีประสิทธิภาพ

## 7. ระยะเวลาเก็บข้อมูล

เราเก็บข้อมูลผู้ใช้จนกว่าจะมีคำขอลบ ผู้ใช้ขอลบข้อมูลได้โดยติดต่อ [privacy@somtum.fun](mailto:privacy@somtum.fun)

เมื่อคุณสมัครบัญชี เราตรวจเครือข่ายที่คุณใช้สมัคร (เพื่อป้องกัน VPN พร็อกซี และการสมัครหลายบัญชี) และอาจสอบถาม proxycheck.io เกี่ยวกับ IP address ของคุณ เราเก็บบันทึกการสมัคร พร้อม IP address เครือข่าย และประเทศ ไว้ 90 วัน แล้วลบทิ้ง

## 8. การคุ้มครองและความปลอดภัยของข้อมูล

เราปฏิบัติตามกฎหมายความเป็นส่วนตัวตามภูมิภาคของผู้ใช้:

- **ผู้ใช้ในประเทศไทย:** [พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA)](https://www.ratchakitcha.soc.go.th/DATA/PDF/2562/A/069/T_0052.PDF)
- **ผู้ใช้ในสหภาพยุโรป:** [General Data Protection Regulation (GDPR)](https://gdpr-info.eu)
- **ประเทศหรือภูมิภาคอื่น:** เราพยายามปฏิบัติตามกฎหมายความเป็นส่วนตัวที่ใช้ในประเทศหรือรัฐของคุณ

มาตรการความปลอดภัยได้แก่:

- การเข้ารหัสรหัสผ่านที่จัดเก็บ (bcrypt + salt)
- การควบคุมการเข้าถึง เพื่อให้เฉพาะผู้มีสิทธิ์เท่านั้นที่จัดการข้อมูลได้
- การตรวจสอบความปลอดภัยเป็นประจำ เพื่อหาช่องโหว่
