# ศูนย์ช่วยเหลือ

มีปัญหาใช่ไหม? ดูว่าควรไปที่ไหนได้ที่นี่

## คำตอบด่วน

คำถามส่วนใหญ่มีคำตอบใน [FAQ](/wiki/FAQ): การเชื่อมต่อ บัญชี คะแนนที่ไม่ถูกส่ง และอื่น ๆ มีอะไรใช้งานไม่ได้? ลองดู[ปัญหาที่พบบ่อย](/wiki/Help_centre/Common_problems)

## เจอบั๊ก หรือเกมแครช?

ดู[การรายงานบั๊ก](/wiki/Help_centre/Reporting_a_bug) (ภาษาอังกฤษ): ต้องบอกอะไรเราบ้าง วิธีเก็บไฟล์ log (ปุ่ม **Export logs** ใน Somtum Launcher รวบรวมให้) และส่งไปที่ไหน

## ติดต่อเรา

| เรื่อง | ช่องทาง |
| :-- | :-- |
| ความช่วยเหลือทั่วไปและบั๊ก | [Discord](https://discord.gg/U6Ztb3mRyz) ของเรา หรือ [support@somtum.fun](mailto:support@somtum.fun) ดู[การรายงานบั๊ก](/wiki/Help_centre/Reporting_a_bug) |
| บัญชีของคุณ (สมัครไม่ได้ เปลี่ยนชื่อ บัญชีหาย) | [accounts@somtum.fun](mailto:accounts@somtum.fun) |
| การลงโทษและการอุทธรณ์ | ล็อกอินแล้วใช้[หน้าอุทธรณ์](/home/appeal) ดู[การลงโทษและการอุทธรณ์](/legal/th/Restrictions) |
| ลิขสิทธิ์ (DMCA) | [dmca@somtum.fun](mailto:dmca@somtum.fun) ดู[ลิขสิทธิ์](/legal/th/Copyright) |
| การคุกคามและการกระทำที่ไม่เหมาะสม | ดู[รายงานการกระทำที่ไม่เหมาะสม](/wiki/Reporting_bad_behaviour/Abuse) |
| ปัญหาความปลอดภัย | [mind@somtum.fun](mailto:mind@somtum.fun) ดู[รายงานปัญหาความปลอดภัย](/wiki/Help_centre/Reporting_a_security_problem) |

ถ้าเป็นไปได้ ให้อีเมลจากอีเมลที่ผูกกับบัญชี เพื่อให้เรารู้ว่าเป็นคุณจริง ๆ เราตอบทางอีเมล ปกติภายในไม่กี่วัน

## รายงานผู้เล่น

ใช้ปุ่มรายงานในเกมหรือในหน้าโปรไฟล์ของผู้เล่นคนนั้น ทีมงานเห็นทุกรายงาน
