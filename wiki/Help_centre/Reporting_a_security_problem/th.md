# รายงานปัญหาความปลอดภัย

somtum.fun ได้รับการดูแลให้ทันสมัยโดยนักพัฒนาที่มีประสบการณ์ และทีมของเราพยายามอย่างเต็มที่ที่จะปกป้องเซิร์ฟเวอร์และแก้ปัญหาความปลอดภัยทุกอย่าง เช่น การหลบเลี่ยงระบบกันโกง การรันโค้ดจากระยะไกล (RCE) หรือช่องโหว่ที่เป็นที่รู้จัก (CVE) เรายังสุ่มตรวจโค้ดของเราด้วย

แต่บางครั้งเราก็ยังพลาด นั่นคือเหตุผลที่เราเปิดซอร์ส [TomYum](https://github.com/somtum-fun/TomYum-OSS) เซิร์ฟเวอร์ที่ somtum.fun ใช้ เพื่อให้คนมากขึ้นช่วยดูและบอกเราว่าตรงไหนผิด

## วิธีรายงาน {id=how}

อีเมลมาที่ **[mind@somtum.fun](mailto:mind@somtum.fun)** โดยตรง พร้อมรายละเอียดให้มากที่สุด โปรดอย่าโพสต์ในที่สาธารณะหรือใน Discord จนกว่าจะแก้เสร็จ เพื่อไม่ให้ใครนำไปใช้กับผู้เล่นคนอื่น

บอกเรา:

1. **ปัญหาคืออะไร** และคนอื่นทำอะไรได้บ้างด้วยปัญหานี้
2. **ทำให้เกิดได้อย่างไร** ทีละขั้น โค้ดหรือวิดีโอสั้น ๆ ช่วยได้
3. **อยู่ตรงไหน**: เว็บไซต์ เซิร์ฟเวอร์เกม ไคลเอนต์ ระบบกันโกง และเวอร์ชันไหน
4. **ติดต่อคุณได้อย่างไร** ถ้าอยากให้เราติดต่อกลับทางอื่นนอกจากอีเมล

## สิ่งที่คุณคาดหวังจากเราได้ {id=what-to-expect}

เราพยายามพูดตรง ๆ ไม่อ้อมค้อมกับทุกคน ไม่ว่าคุณจะเป็นคนเจอปัญหาหรือได้รับผลกระทบ ถ้ามีอะไรผิดพลาด เราจะบอกว่าเกิดอะไรขึ้นและเราทำอะไรไปแล้ว

เจอบั๊กที่ไม่เกี่ยวกับความปลอดภัย? ดู[การรายงานบั๊ก](/wiki/Help_centre/Reporting_a_bug)
