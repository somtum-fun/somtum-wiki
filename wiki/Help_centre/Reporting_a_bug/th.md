# การรายงานบั๊ก

เจออะไรพัง หรือเกมแครช? บอกเรา การแก้ไขส่วนใหญ่เริ่มจากรายงานของผู้เล่น หน้านี้บอกว่าต้องส่งอะไรบ้างเพื่อให้เราหาปัญหาได้เร็ว

ก่อนรายงาน ลองดู[ปัญหาที่พบบ่อย](/wiki/Help_centre/Common_problems) และ [FAQ](/wiki/FAQ) ปัญหาของคุณอาจมีวิธีแก้อยู่แล้ว

## รายงานที่ไหน {id=where}

- **[เซิร์ฟเวอร์ Discord](https://discord.gg/U6Ztb3mRyz) ของเรา:** เร็วที่สุด และทีมงานถามคำถามคุณได้
- **อีเมล [support@somtum.fun](mailto:support@somtum.fun)** จากอีเมลของบัญชี ถ้าไม่อยากใช้ Discord แนบไฟล์ log มากับอีเมล

สำหรับคนโกงหรือผู้เล่นที่ไม่สุภาพ ให้ใช้ปุ่มรายงานแทน (ดู[ศูนย์ช่วยเหลือ](/wiki/Help_centre#reporting-a-player)) สำหรับปัญหาความปลอดภัย (วิธีโกงเซิร์ฟเวอร์ หรือดูข้อมูลของคนอื่น) ดู[รายงานปัญหาความปลอดภัย](/wiki/Help_centre/Reporting_a_security_problem) และอย่าโพสต์ในที่สาธารณะ

## ต้องบอกอะไรเรา {id=what}

1. **เกิดอะไรขึ้น** และคุณคาดว่าควรเกิดอะไรแทน
2. **ทำให้เกิดซ้ำได้อย่างไร** ทีละขั้น ถ้าทำได้
3. **เกิดเมื่อไร** (วันที่ เวลา และเขตเวลาของคุณ) เราจะหาใน log ของเซิร์ฟเวอร์
4. **ไคลเอนต์และเวอร์ชัน**: TumThai หรือ TumThai!Next (แสดงที่ด้านล่างของ Settings), osu!(stable) กับ Somtum Patcher (เวอร์ชันของ Patcher และของ osu! ที่ **Options → General → Updates**) หรือไคลเอนต์รุ่นเก่ารุ่นไหน (เช่น b20130606.1)
5. **ระบบของคุณ**: Windows (เวอร์ชันไหน), Linux (distribution ไหน และใช้ Wine หรือไม่), macOS หรือ Android
6. **ชื่อผู้ใช้ของคุณ** และลิงก์ของบีทแมพหรือคะแนน ถ้าเกี่ยวข้อง
7. **ไฟล์ log** สำหรับการแครชหรือปัญหาของไคลเอนต์ (ดู[ด้านล่าง](#logs)) ภาพหน้าจอหรือวิดีโอสั้น ๆ ก็ช่วยได้

## การเก็บไฟล์ log {id=logs}

### ด้วย Somtum Launcher (ง่ายที่สุด) {id=logs-launcher}

1. ใน Somtum Launcher เปิด **Settings → Advanced options** แล้วเปิด **Record logs**
2. เปิดเกมจาก launcher แล้วทำให้ปัญหาเกิดซ้ำ
3. กลับมาที่ launcher กด **Export logs** ใน **Settings → Advanced options** บน Linux ให้รัน `somtum export-logs`
4. ไฟล์ zip จะขึ้นบน Desktop: ส่งมากับรายงาน

ไฟล์ zip มี log ของ launcher สิ่งที่เกม log ไว้ log ของ TumThai เอง โฟลเดอร์ Logs ของ osu! log การแครชของไคลเอนต์รุ่นเก่า และรายงานข้อผิดพลาดของ Windows สำหรับโปรแกรมเหล่านี้ ไม่มีรหัสผ่าน ข้อมูลล็อกอิน หรือการตั้งค่าเกมของคุณ การบันทึก log อาจทำให้ประสิทธิภาพลดลงเล็กน้อย ปิด **Record logs** เมื่อส่งเสร็จแล้ว

### TumThai {id=logs-tumthai}

TumThai เก็บ log ไว้เสมอ ใน TumThai เปิด **Settings → General** แล้วกด **Export logs** ระบบจะบันทึกไฟล์ zip ให้คุณส่ง ปุ่ม **Open TumThai folder** ที่เดียวกันจะแสดงไฟล์เหล่านั้นในโฟลเดอร์ `logs`

### osu!(stable) กับ Somtum Patcher {id=logs-stable}

Somtum Patcher เขียน `patcher.log` ในโฟลเดอร์ `Logs` ภายในโฟลเดอร์ osu! ส่งไฟล์นั้นมา หรือใช้ [Export logs](#logs-launcher) ของ launcher ซึ่งรวมไฟล์นี้ไว้แล้ว

### ไคลเอนต์รุ่นเก่า (2008 ถึง 2015) {id=logs-legacy}

เมื่อไคลเอนต์รุ่นเก่าแครช มันจะเขียน log การแครชไว้ในโฟลเดอร์ของตัวเอง ถ้าเปิด **Record logs** ใน Somtum Launcher มันจะเขียน log ของทั้งเซสชันตั้งแต่เริ่มเปิดด้วย [Export logs](#logs-launcher) ของ launcher เก็บรวบรวมทั้งสองอย่าง

## หลังจากนั้น {id=next}
